# RV32 Architecture Core

A self-paced computer architecture project implementing a 32-bit RISC-V processor in SystemVerilog.

The project will include a single-cycle core and a five-stage in-order pipelined core using a limited RV32I instruction subset.


## Project Structure

- `rtl/` — SystemVerilog design modules
- `tb/` — Testbenches and assertions
- `docs/` — Design and ISA documentation
- `model/` — Reference models and helpers
- `programs/` — RISC-V assembly tests
- `scripts/` — Build and verification scripts
- `results/` — Selected test and experiment results
- `experiments/` — Small programs and tests used to explore computer architecture ideas

## Status

Currently working through the RV32I instruction set and building the initial RTL and verification infrastructure.
