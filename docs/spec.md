## Scope

This project will implement a 32-bit RISC-V processor in SystemVerilog.
The project will first build a single-cycle processor to serve as a
correct reference implementation, followed by a five-stage in-order
pipelined processor.

Both processors will implement a limited 15-instruction subset of RV32I.
The pipelined processor will later be extended with more realistic
architectural features including variable-latency data memory, a data
cache, and branch prediction.

The goal of the project is to understand how an ISA is implemented by a
processor microarchitecture and to build, verify, and evaluate a working
processor design. The processor is educational and is not intended to
implement the complete RISC-V ISA or support a full operating system.
